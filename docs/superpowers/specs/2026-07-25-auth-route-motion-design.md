# 认证页面短距定向切换动画设计

## 目标

优化登录、注册、忘记密码和重置密码页面之间的切换，使动画更流畅，同时保持现有页面结构、表单状态、接口调用、Turnstile 和路由行为不变。

## 范围

- `/login`
- `/register`
- `/forgot-password`
- `/reset-password`

不修改控制面板及其他网站页面的路由动画。

## 视觉方案

采用已确认的 **A：短距定向滑入**。

- 首次从非认证页面进入认证流程时，保留一次轻量的外层卡片入场效果。
- 认证页面互相切换时，背景、左侧品牌区和外层卡片保持视觉稳定，不重复播放整卡入场动画。
- 只让右侧表单内容移动约 `18px` 并淡入。
- 前进切换从右侧进入，返回切换从左侧进入。
- 进入动画约 `340ms`，使用 `cubic-bezier(0.22, 1, 0.36, 1)`；避免大幅位移、弹跳和长时间模糊。
- 登录/注册顶部选中滑块使用约 `320ms` 的平滑位移动画，与表单方向同步。

## 路由方向

认证流程使用以下顺序判断动画方向：

1. 登录
2. 注册或忘记密码
3. 重置密码

从较低顺序进入较高顺序为前进，从右侧滑入；反向为返回，从左侧滑入。同级或无法判断方向时使用轻量淡入，不使用大幅滑动。

## 实现结构

1. 增加一个小型认证路由动画工具，集中保存认证路径顺序并解析 `initial`、`forward`、`backward` 和 `neutral` 状态。
2. 在现有路由守卫开始处计算本次认证页面切换方向，并写入目标路由的元信息。
3. `AuthLayout` 根据路由元信息增加对应状态类：
   - 首次进入允许外层卡片入场。
   - 认证页互切时禁用 `shell-enter`。
   - 仅为右侧内容应用短距定向动画。
4. `AuthModeTabs` 改为单独的选中滑块层，活动文字位于滑块上方；前进和返回时分别播放左右方向动画。
5. 保留现有 RouterLink、表单事件和业务组件，不拦截、不延迟实际导航。

## 性能与可访问性

- 动画仅使用 `transform` 和 `opacity`，避免触发布局抖动。
- 动画区域增加合理的合成提示，但不长期滥用 `will-change`。
- 保持键盘焦点、链接语义和 `aria-current` 不变。
- 在 `prefers-reduced-motion: reduce` 下关闭位移、淡入和滑块动画。
- 移动端使用相同节奏，但位移缩短，避免窄屏晃动。

## 验证

- 单元测试覆盖认证路径方向解析。
- 表现测试确认外层卡片不会在认证页互切时重复入场。
- 组件测试确认登录/注册标签仍保留正确链接和 `aria-current`。
- 浏览器验证登录 → 注册、注册 → 登录、登录 → 忘记密码、忘记密码 → 登录，以及重置密码相关返回路径。
- 执行前端类型检查、认证相关测试和生产构建。

## 非目标

- 不增加全站路由动画。
- 不修改表单字段、校验、登录注册接口或密码重置业务逻辑。
- 不修改控制面板视觉风格。
